# Demo example images

These five unmodified low-light images are from the LOL-v1 test split (`test/low/`): `111.png`, `146.png`, `22.png`, `493.png`, and `778.png`.

- Dataset: [Deep Retinex Decomposition for Low-Light Enhancement (BMVC 2018)](https://daooshee.github.io/BMVC2018website/).
- Download source: [LOL-v1 test archive mirror](https://huggingface.co/datasets/okita-souji/LOLv1/blob/main/test.zip).
- Original dataset download links are also listed in Section 2 of the repository README.

They are bundled for trying the inference demo without downloading the full dataset. Image credits belong to the original dataset authors; the repository's code license does not relicense these images.

Click a thumbnail in the app's **Example images** section, then click **Enhance image**. Your selected checkpoint, Gamma, brightness, image size, and self-ensemble settings are retained. Start with `LOL_v1.pth`, Gamma 1.0, and Output brightness 1.0.
